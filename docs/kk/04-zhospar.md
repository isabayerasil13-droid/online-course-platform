# 4. Әзірлеудің кезеңдік жоспары

Мерзімдер мен нақты орындаушылар әлі келісілген жоқ.

## 0-кезең — Талдау және сәулет (ағымдағы)
- [x] Тақырыпты таңдау: онлайн курстар.
- [x] Үш рөл мен негізгі функцияларды анықтау.
- [x] Үш сәулетті алты критериймен салыстыру.
- [x] Django модульдік монолиті мен PostgreSQL таңдау.
- [x] Деректер моделін, ADR және диаграммаларды дайындау.
- [x] Орысша және қазақша құжаттарды жазу.
- [ ] Нәтижені оқытушымен және командамен келісу.

**Дайындық өлшемі:** команда шешімді, бағалауды және дерекқорды түсіндіре алады.

## 1-кезең — Дайындық
- [ ] Міндеттерді командаға бөлу.
- [ ] Category, Review, Quiz/Question модельдерін және құқықтарды нақтылау.
- [ ] Пайдаланушы сценарийлері мен API жобалау.
- [ ] Django жобасын және PostgreSQL ортасын орнату.
- [ ] Git тармақтары мен PR ережелерін бекіту.

## 2-кезең — MVP құру
- [ ] `accounts`: рөлдер және жүйеге кіру.
- [ ] `courses`: курс жасау, қарау, жариялау.
- [ ] `lessons`: сабақтар және материалдар.
- [ ] `enrollments`: курсқа тіркелу.
- [ ] `assignments`: тапсырмалар, жауаптар, бағалар.
- [ ] `progress`: оқу барысы және нәтижелер.
- [ ] Негізгі интерфейс пен әкімші панелі.

**Нәтиже:** оқытушы курс жариялайды, студент тіркеліп тапсырма тапсырады, оқытушы бағалайды.

## 3-кезең — Тестілеу және қорғау
- [ ] Рөлдерді, CRUD операцияларын, БД шектеулерін тестілеу.
- [ ] Қате деректер мен теріс сценарийлерді тексеру.
- [ ] Жеке деректерсіз демонстрациялық ақпарат дайындау.
- [ ] Құжаттарды және диаграммаларды жаңарту.
- [ ] Презентация мен демонстрация әзірлеу.

## 4-кезең — Қосымша мүмкіндіктер (міндетті емес)
Пікірлер, есептер, автоматты тесттер, хабарландырулар, сертификаттар, бейне және төлемдер. Тұрақты MVP дайын болғаннан кейін ғана.

**Қауіптер:** функционалдың шамадан тыс кеңеюі, модельдердің сәйкес келмеуі және уақыт тапшылығы; шешім — алдымен толық бір оқу сценарийін аяқтау.
