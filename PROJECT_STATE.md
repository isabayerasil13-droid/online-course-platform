# PROJECT_STATE — OpenStudy

**Дата:** 2026-10-20. **Этап:** минимальный работающий прототип (MVP-демо), не production.
**Репозиторий:** isabayerasil13-droid/online-course-platform.
**СУБД:** SQLite для локальной демонстрации; PostgreSQL — архитектурная цель и опциональная конфигурация.

## Что реализовано
- Django-проект `config` и приложение `courses`.
- Модели Course, Lesson, Enrollment, LessonProgress.
- Каталог курсов, поиск по тексту и фильтр категорий.
- Страница курса с обложкой-картинкой и текстовыми уроками.
- Регистрация, вход, выход Django auth.
- Запись на курс, отметки прохождения, страница с процентами.
- Административная панель для курсов и уроков.
- Команда `seed_demo` для 6 примеров, локальные SVG-картинки.
- Тесты основных сценариев, документация RU и KK.
- Инструкция запуска и показа команде.

## Не сделано
- Реальное видео, тесты/задания/оценки, загрузки, платежи, сертификаты.
- Самостоятельный кабинет преподавателя: добавлять курсы может только уполномоченный пользователь через Django admin.
- Отдельные Django-приложения `accounts`, `lessons`, `progress` и др. пока не выделены: это запланированная целевая архитектура.
- Публичный хостинг, production-конфигурация, нагрузочное тестирование.

## Следующие шаги
1. Пройти сквозной сценарий и показать коллегам.
2. Уточнить требования MVP с преподавателем.
3. При необходимости настроить PostgreSQL как основную БД.
4. Разделить `courses` на логические Django-приложения по ADR.
5. Добавить задания, тесты и оценки после согласования.
