# Платформа онлайн-курсов / Online Course Platform

Учебный командный проект по проектированию и оценке архитектуры программного обеспечения.

**Этап:** документация и планирование. Код приложения пока не реализован.
**Язык основной документации:** русский. [Қазақша нұсқа](README_KK.md).
**Стек (планируется):** Python, Django, PostgreSQL, Django ORM.
**Архитектура:** модульный монолит. **Команда:** 3–5 человек.

## Идея
Платформа позволяет преподавателям создавать курсы и уроки, студентам записываться и проходить обучение, отправлять задания, а администраторам — управлять системой. Сохраняются оценки и прогресс.

## Что уже принято
- Сравниваются монолит, модульный монолит и микросервисы.
- Результаты оценки: **20 / 24 / 15** баллов соответственно (шесть критериев, оценка 1–5).
- Выбран **модульный монолит**: единый Django-проект с отдельными приложениями по функциональности.
- Выбрана реляционная СУБД **PostgreSQL**; доступ к данным — Django ORM.
- Микросервисы не нужны на старте; при росте можно выделить обработку видео, платежи, уведомления и аналитику.
