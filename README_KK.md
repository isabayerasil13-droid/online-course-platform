# Онлайн курстар платформасы / Online Course Platform

Бағдарламалық қамтамасыз ету сәулетін жобалау және бағалау бойынша оқу топтық жобасы.

**Кезеңі:** құжаттау және жоспарлау; қолданба коды әлі жазылған жоқ.
**Негізгі құжаттама:** орысша — [README.md](README.md); осы файл — қазақша нұсқа.
**Жоспарланған технологиялар:** Python, Django, PostgreSQL, Django ORM.
**Сәулет:** модульдік монолит. **Команда:** 3–5 адам.

## Жоба идеясы
Оқытушылар курстар мен сабақтар жасайды; студенттер курсқа тіркеліп, тапсырма орындайды; оқытушылар жұмыстарды тексереді; жүйе бағалар мен үлгерім барысын сақтайды; әкімші пайдаланушылар мен контентті басқарады.

## Қабылданған шешімдер
- Қарастырылған нұсқалар: монолит, модульдік монолит, микросервистер.
- Бағалау нәтижелері: тиісінше **20 / 24 / 15** ұпай (алты критерий, 1–5 шкаласы).
- **Модульдік монолит** таңдалды: функционалдық Django қолданбалары бар бір жүйе.
- Байланысқан деректерге **PostgreSQL** реляциялық ДҚБЖ, оған қатынау үшін **Django ORM** таңдалды.
- Бастапқы кезеңде микросервистер қажет емес.
