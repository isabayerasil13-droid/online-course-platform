# 6. Командалық жұмыс

## 3–5 адамнан тұратын команда
- Backend: модельдер, бизнес-логика, құқықтар, API.
- Frontend: курстар, сабақтар, кіру және оқу барысы беттері.
- QA / дизайн: тестілеу, интерфейс және негізгі сценарийлер.
- Үйлестіруші: біріктіру, кодты қарау, құжаттама және қорғау.
Бір адам бірнеше рөлді атқара алады.

## 4 адамға арналған алдын ала бөлу
| Қатысушы | Жауапкершілік |
|---|---|
| 1 | Accounts, авторизация, Django негізі |
| 2 | Courses, Lessons, санаттар және материалдар |
| 3 | Enrollments, Assignments, Progress, PostgreSQL модельдері |
| 4 | Интерфейс, тесттер, құжаттама, демонстрация |

Бұл тек ұсыныс; нақты орындаушылар кейін бекітіледі.

## Git ережелері
Әр тапсырмаға жеке тармақ пен Pull Request жасау; басқа қатысушы өзгерісті қарайды. Деректер моделі өзгерсе, оны алдын ала келісу керек. Сәулеттік шешім өзгергенде жаңа ADR қосылады. Құжаттар орысша және қазақша сәйкестікте жаңартылады. Құпия кілттер мен жеке деректер репозиторийге салынбайды.
